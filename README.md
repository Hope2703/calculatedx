# CalculatedX

CalculatedX est une calculatrice modulaire développée en Python dans le cadre des semaines 8 et 9.

## Objectifs

Le projet permettra progressivement de réaliser :

- des opérations arithmétiques ;
- des opérations scientifiques ;
- des opérations trigonométriques ;
- la gestion d'un historique ;
- la gestion d'une mémoire.

Le projet applique également les principes de programmation orientée objet et un workflow collaboratif Git/GitHub.

## Équipe

Projet réalisé par une équipe de 4 développeurs.
